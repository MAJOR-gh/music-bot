# Changelog

## v2.0 — переработка: стабильный звук, YouTube Music, Spotify, Last.fm

### 🎧 Звук и стабильность
- **yt-dlp вынесен в отдельные процессы.** Раньше поиск/разбор трека грузил
  процесс бота, и звук подёргивался, пока кто-то искал песню.
- **Автообновление yt-dlp** при старте и раз в 12 часов: устаревший yt-dlp ловит
  403 от YouTube — трек рвался или пропадал.
- **Голос переподключается сам**, если сеть/туннель моргнули (раньше бот молча
  вылетал из канала). Бот заходит в канал «заглушённым» — меньше трафика.
- **Следующий трек качается заранее**, пока играет текущий, — без пауз.
- Если YouTube не отдал трек, бот ищет ту же песню на **SoundCloud**; если трек
  так и не сыграл — пишет об этом в чат, а не молчит.

### 🔎 Новые источники
- `/play` получил параметр **`source`**: YouTube, **YouTube Music**, **Spotify**, **Last.fm**.
- **Ссылки Spotify** — трек, альбом, плейлист (без ключей). Звук бот находит на YouTube Music.

### 🐛 Исправления
- `/leave`, выход по простою и уход всех из канала не убирали панель и не
  останавливали плеер, если очередь была пуста.
- Выход по простою мог оборвать сам себя — бот оставался в канале.
- **Стоп** (команда и кнопка) при включённом повторе возвращал трек обратно.
- **⏮️ «В начало»** при повторе дублировал трек в очереди.
- **`/skip`** не работал на паузе; «Пропустить» во время скачивания трека ждал
  конца скачивания.
- После `/leave` + `/join` старый плеер продолжал смотреть в старое подключение.
- Временные файлы треков не удалялись на Windows (FFmpeg ещё держал файл) и копились.
- `/queue` с длинными названиями падал (лимит Discord 1024 символа на поле).
- Устаревший список поиска выглядел живым, а клик давал «Ошибка взаимодействия».
- Любая ошибка в команде теперь пишется в консоль с трейсбеком, а человеку
  приходит понятный ответ вместо «Приложение не отвечает».
- Убрано ложное предупреждение «Privileged message content intent is missing».

## v1.1 — повтор, перелистываемый поиск, оптимизация

### 🔁 Повтор (repeat)
- Новая команда **`/repeat [режим]`** — выкл / один трек / вся очередь. Без
  аргумента переключает по кругу.
- Кнопка **🔁** на живой панели-плеере: один клик меняет режим, вид кнопки и
  футер эмбеда показывают текущий режим.
- **Один трек** — текущий трек играет заново по кругу. **Вся очередь** — каждый
  отыгравший трек уходит в конец, очередь крутится бесконечно.
- **`/skip`** (и кнопка ⏭️) перебивают повтор: пропуск всегда идёт к следующему,
  не возвращая текущий трек.

### 🔎 Перелистываемый поиск
- Текстовый поиск `/play` теперь отдаёт до **25 вариантов** (настройка
  `SEARCH_RESULTS`) вместо 5.
- Выпадашка листается по **10 на страницу** кнопками **◀ Назад / Вперёд ▶** с
  индикатором «Стр. X/Y».

### ⚙️ Оптимизация
- Выделенный пул потоков под `yt-dlp` — извлечение треков не конкурирует с
  event-loop'ом, нагрузка предсказуема.
- Ускоренное извлечение YouTube (лёгкие клиенты android/web) — быстрее и реже
  ловит `403 / Sign in to confirm`.
- Устойчивый разбор кодека (`ffprobe` с `method="fallback"`), `cachedir=False`.

### 🐛 Исправления
- **Дубли команд** в списке Discord: старт бота гарантированно чистит глобальные
  команды, оставляя только гильдийные (по одной копии). Если дубли остались —
  это кэш клиента, обнови приложение Ctrl+R.

## v1.0 — первый релиз 🎵

**Chernarus FM** — музыкальный бот для Discord. Стримит аудио с YouTube и
SoundCloud прямо в голосовой канал, с очередью, кнопками управления и живой
панелью «сейчас играет». Аудио идёт напрямую, без скачивания на диск.

### ▶️ Воспроизведение
- **`/play <ссылка или текст>`** — основная команда.
  - **Ссылка** (YouTube/SoundCloud) — играет сразу.
  - **Текст** — бот ищет **топ-5 вариантов** и показывает выпадающий список с
    названием и длительностью. Удобно, когда у трека есть версии *longmix,
    sped up, slowed, remix* и т.д. — выбираешь нужную сам.
- **Очередь на каждый сервер.** Добавляй треки во время игры — они встанут в
  очередь и заиграют по порядку, ничего не прерывая.

### 🎛️ Живая панель-плеер
- Под играющим треком — панель с кнопками: ⏸️ **Пауза** · ▶️ **Продолжить** ·
  ⏭️ **Пропустить** · ⏹️ **Стоп**.
- Панель **обновляется в реальном времени** при смене трека, паузе и пропуске:
  показывает название, длительность, автора, кто заказал, обложку и блок
  **«Далее в очереди»** (топ-5).
- Кнопки и слэш-команды синхронизированы — что бы ты ни нажал, панель отражает
  актуальное состояние.

### ⌨️ Команды
| Команда | Действие |
|---|---|
| `/join` | Подключить бота к твоему голосовому каналу |
| `/leave` | Отключиться и очистить очередь |
| `/play <запрос>` | Играть по ссылке или искать по тексту (выбор из вариантов) |
| `/skip` | Пропустить текущий трек |
| `/pause` · `/resume` | Пауза / продолжить |
| `/stop` | Остановить и очистить очередь (бот остаётся в канале) |
| `/queue` | Показать очередь |
| `/nowplaying` | Что играет сейчас |

### 🤖 Автоматика
- ⏱️ Авто-отключение через 5 минут бездействия (настраивается `IDLE_TIMEOUT`).
- 👥 Авто-отключение, когда в канале не осталось людей.
- 🔒 Защита от запуска нескольких плееров на один сервер.
- 🔁 Авто-переход к следующему треку и авто-reconnect потока при обрывах.

### 🛠️ Под капотом
- **discord.py 2.7** (поддержка E2EE/DAVE-голоса) + **yt-dlp** + **FFmpeg**.
- Поиск вариантов через быстрый flat-режим yt-dlp: поток скачивается только для
  выбранного трека.
- Конфигурация через `.env` (токен, ID сервера, таймаут, путь к FFmpeg).
- Очередь и состояние — отдельные на каждый сервер.
